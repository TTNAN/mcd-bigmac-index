⚙️ 数据怎么来的

1. 找门店

query-nearby-stores 按城市 + 核心商圈，取前 3 家营业中的麦当劳。

2. 拉菜单

query-meals 读取实时菜单，匹配巨无霸、中薯条、中可乐和巨无霸三件套。

3. 官方核价

calculate-price 让麦当劳自己算出到手价，不是爬虫，也不是估算。

指数主序列固定用上海南京东路同一家门店，保证时间可比。所有原始数据每天提交在仓库 data/ 目录，可自由使用。
